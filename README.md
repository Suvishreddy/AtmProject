# AtmProject
This project is aimed at developing a simple Automated Teller Machine (ATM) system using Core Java. The objective is to simulate a basic ATM functionality where users can perform essential banking operations such as checking their balance, withdrawing money, and depositing funds.
Predefined Atm Number and Atm Pin: 
Atm Number:- 12345
Atm Pin:- 123

Features:

User Authentication:
The system should allow users to log in with their Account Number and PIN.
Authentication will be verified by comparing the input credentials with stored ones 

Banking Operations:
Check Balance: Users can view their account balance.
Withdraw Money: Users can withdraw a specific amount from their account, ensuring they don't exceed the available balance.
Deposit Money: Users can deposit funds into their account.
Error Handling:The system should include error handling for invalid PINs, insufficient funds during withdrawal, and invalid inputs for amounts.
Informative messages should be displayed to users for these error scenarios.
